# TerranSoul
Your 3D AI companion for everyday life or enterprise staff.

**[📄 Research Paper — *LLM Brain*](https://terransyn.github.io/TerranSoul/LLM-Brain-Design-Research-Paper/)** — A research report (ZorkGPT × external-memory bench, May–June 2026) evaluating the need for memory, knowledge, and RAG layers in LLM agents. It isolates three claims on Zork I: external memory lifts an unaided weak local model from 0 to 10–20, reliable delivery of a taught solution drives a deterministic 350/350, and frontier-solving knowledge can be distilled through memory rather than weights.
