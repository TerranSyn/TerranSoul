TerranSoul · Brain Architecture

A local-first brain that remembers, retrieves, and improves itself

TerranSoul's brain is an external memory-and-knowledge server: a three-tier SQLite store feeds a six-signal hybrid retriever before every turn, a typed knowledge graph enables multi-hop recall, and a closed write → manage → read loop lets the system learn from its own outcomes — all reached by any client over the Model Context Protocol (MCP).

01What the brain is

Most agents keep memory inside the model — in the weights or the context window. TerranSoul takes the opposite bet: memory is external, a queryable Rust service that any client reads and writes through a tool interface. That makes memory observable, probeable, editable, and shareable across clients in ways a model-internal store can never be.

The same brain serves the desktop chat app, coding agents (Claude Code / Copilot / Codex / Cursor), and benchmark runners — over MCP. The Rust AppStateGateway is the single owner of all memory CRUD: there are no private caches in clients.

Nodes marked NEW below are cognitive / self-improvement capabilities adopted generically from a GENesis-AGI study and specified in docs/genesis-agi-brain-adoption.md — clean-room, no code copied. Status (2026-06-08): schema V30 + SHIPPED P1 outcome-classified write-back · P2 procedural ledger · P3 activation signal · P4 consolidation provenance/rollback · P6 echo-collapse hot-path · P7 floor-gated KG auto-link-on-write · P8 effort triage + graded reflection depth · P9 zero-LLM idle validation cognition; IN-PROGRESS P5 session primer (chat.rs inject) and P8 live-path wiring.

03Layer by layer

L0 · CLIENTS

Any client, one brain

The desktop VRM chat, coding agents, bench runners, and the Real-E2E harness all talk to the same brain over MCP. Knowledge one client writes is legible to the next.

L1 · PROTOCOL & GATEWAY

MCP + AppStateGateway

The MCP brain server exposes brain_search, brain_suggest_context, brain_ingest_lesson, and KG tools. Every CRUD call funnels through the Rust AppStateGateway — the single source of truth, no private client caches.

L2 · TRIAGE NEW

Spend effort where it pays

A per-request effort triage (SKIP / LIGHT / NORMAL / FULL) avoids running the full pipeline on trivial turns SHIPPED 2026-06-08 (pure triage_effort in brain/intent_classifier.rs + graded ReflectionDepth; live-path wiring is the remaining follow-up), and a zero-LLM session primer IN-PROGRESS injects ~300 tokens of durable context once per session straight from the DB. The primer core + builder have landed (memory/session_primer.rs: format_primer / build_session_primer, plus top_activation_procedures / latest_session_reflection); the remaining step is to inject it once per conversation in commands/chat.rs.

L3 · HYBRID RAG

Many retrievers, one fused list

Vector (HNSW), lexical (FTS5/BM25), KG graph-seed, and freshness retrievers are fused by reciprocal-rank fusion, then refined by HyDE (cold queries), a cross-encoder reranker, and a relevance cutoff. See §04.

L4 · MEMORY + KG

Three tiers + a typed graph

Short (ring buffer) → working (session) → long (durable, decaying). A typed memory_edges graph supports multi-hop recall and explicit contradicts edges. See §05.

L5 · STORAGE

SQLite + tiered vector index

One SQLite (WAL) database holds memories, edges, versions, and FTS5 — so a single hybrid query fuses lexical, vector, and graph without a cross-store join. Vector search scales across Linear → TurboQuant → IVF-PQ → HNSW tiers.

04Hybrid retrieval — the six-signal blend

Before every chat turn the brain assembles a [LONG-TERM MEMORY] block. Each candidate memory is scored by a weighted blend of independent signals, then the per-retriever ranked lists are fused with reciprocal-rank fusion (RRF, k=60) — so a failing retriever contributes nothing rather than poisoning the top-k.

score = 0.40·vector + 0.20·keyword + 0.15·recency + 0.10·importance + 0.10·decay + 0.05·tier_priority × activation_multiplier (NEW: access_freq × connectivity × source half-life × proper-noun 2×)

The default weights were validated by an A/B sweep: collapsing the blend to vector-only drops R@10 from 64.5% to 54.5% (−10 pp), confirming the multi-signal design empirically. On top of fusion: Contextual Retrieval situates a chunk before embedding, HyDE embeds a hypothetical answer for cold/abstract queries (gated per query-class), a cross-encoder LLM-as-judge reranks the top candidates, and a relevance cutoff (0.30) drops weak memories entirely rather than padding the prompt.

Adopted refinements NEW

  • Activation signal (7th term) SHIPPED 2026-06-08: frequently-recalled, well-connected memories get a log-scaled lift (access_freq × graph connectivity from a batched edge_degrees() over memory_edges), applied as a bounded attenuate-only multiplier ([0.6, 1.0]) after RRF in both hybrid_search_rrf and hybrid_search_rrf_with_intent — self-reinforcing recall with no ordering regression (25 tests green). Source-aware half-lives and the proper-noun 2× bonus remain optional follow-ups.
  • Echo-collapse diversity pass SHIPPED 2026-06-08: near-duplicate results (Jaccard ≥ 0.80) are demoted so the block carries diverse evidence, not five paraphrases of one fact. The embedding-free core (fusion.rs: token_set / jaccard / echo_collapse_multipliers) and its hot-path wiring have landed: an attenuate-only post-RRF pass (EchoCollapseConfig + apply_echo_collapse in memory/store.rs) runs after the activation re-sort and before select_diversified_ranked in both hybrid_search_rrf and hybrid_search_rrf_with_intent — orthogonal axes (content Jaccard vs session-id cap), proven no-op on a distinct corpus so it cannot regress retrieval.
  • Per-request effort triage + graded reflection depth SHIPPED 2026-06-08: a pure triage_effort classifier (brain/intent_classifier.rs) maps each turn to Skip / Light / Normal / Full from generic structural signals only (token count, per-token length, complexity-cue count, multi-question punctuation — no domain verb lists), and on the write side ReflectionDepth::from_effort grades reflection as a strict prefix chain (Skip → Summary → Facts → Full) in memory/reflection.rs so trivial sessions don't pay full reflection cost. Thresholds are brain-resident; wiring the verdict into the live chat/reflect callers is the remaining follow-up.

05Memory tiers, cognitive kinds & the knowledge graph

Memory promotes short → working → long; the long tier decays and is garbage-collected under a capacity bound that protects important/protected rows. Every long memory carries a cognitive kind — episodic, semantic, procedural, or judgment — each with its own decay half-life.

TYPED KG

memory_edges

Object/location and entity relations are promoted into a typed graph (idempotent on (src, dst, rel_type)), enabling multi-hop traversal and explicit contradicts edges. Mem0-style LLM-arbitrated conflict resolution keeps the store consistent.

PROCEDURAL LEDGER SHIPPED 2026-06-08

Skills that earn trust

Learned procedures become first-class: Laplace-smoothed confidence (s+α)/(s+f+α+β) (α2/β1 → ~0.67 cold start) with success/failure counts, promotion L4→L1 as evidence accrues, demotion on repeated failure, and quarantine after 3 consecutive failures — so the brain only auto-applies skills it has earned trust in. Persisted via store.record_procedure_outcome over the schema-V30 columns (memory/procedural.rs).

AUTO-LINK SHIPPED 2026-06-08

Connect on write

New durable facts are linked to their nearest neighbours with typed extends/supports edges (source=Auto) at write time, so the graph densifies as knowledge arrives rather than only during batch consolidation. AutoLinkConfig + auto_link_on_write in memory/store.rs run an embedding-free jaccard token-set pass at the end of MemoryStore::add — effort-gated and floor-gated (0.35) so cold or unrelated writes create zero edges, keeping retrieval (LongMemEval) unaffected; the LLM proposer later upgrades the coarse relations.

SAFE CONSOLIDATION SHIPPED 2026-06-08

N→1 without losing the plot

Memory synthesis ships provenance + reversible rollback: each synthesized parent is stamped with a consolidation_run_id, and store.rollback_consolidation_run reverses a whole run (un-links children, drops the synthesis edges, deletes the parents). Synthesis is already non-destructive (children preserved via parent_id; Summary rows excluded from re-merge), so reversibility — not a shrink guard — is the real safety net. Adversarial faithfulness review remains a follow-up.

06The self-improvement loop — write → manage → read

What turns a memory store into an adaptive brain is the closed loop around it. After each turn the outcome is classified, procedures are reinforced or demoted, memory is consolidated safely, and the next turn recalls what the agent actually uses.

07Autonomous skill auto-generation PLANNED · SPEC-033

The self-improvement loop above optimizes, reinforces, imports, and promotes skills — but it cannot yet mint a brand-new skill from observed behaviour. This layer (a generic pattern reverse-engineered clean-room from Hermes-Agent, no upstream code/prompts/schema vendored) adds exactly that one missing capability and nothing the brain already has. Net new surface for the whole phase: one module (brain/skill_synthesizer.rs), one outcome predicate (synthesizes_new_skill), and one new source="synthesized" value in the existing tool_skills catalog. Everything else is reuse of §05/§06 machinery.

The new capability in one sentence: an autonomous closed learning loop — observe → author → validate → register → reuse → refine — that detects a recurring or workaround-successful trajectory, creates a fresh reusable skill, governs it through the existing §05 procedural ledger (born cold at L4, advisory-only), surfaces it by description, and refines it on every subsequent use — all bounded and anti-recursive. How it extends the existing layers — never duplicates them

OBSERVE · HERMES-ADOPT-1

Trigger on the existing taxonomy

One new synthesizes_new_skill() predicate sits alongside §06's reinforces_procedure / penalises_procedure in memory/outcome.rs, making the already-earmarked workaround_success → extract a NEW procedure path real. It runs behind the same AutoLearnPolicy / effort triage (§04) so authoring never fires an LLM every turn.

AUTHOR · HERMES-ADOPT-2

Mint text that did not exist

skill_synthesizer.rs is the sibling of skill_optimizer (which only improves existing text). It reuses extract_turn_pairs_public to get the trajectory, then an auxiliary-LLM pass extracts a typed candidate — generic over any trace, no hardcoded domain knowledge per AGI-purity, with fail-loud rejection on malformed candidates.

REGISTER · HERMES-ADOPT-3

Born into the existing ledger

Written through the existing tool_skills catalog with a new source="synthesized" value (idempotent on (source, name)) and a paired procedural twin born at TIER_COLD/L4 advisory-only. Born-cold is the no-regression guarantee: an unproven skill cannot change live behaviour until it earns promotion through the §05 procedural ledger.

REUSE · HERMES-ADOPT-4

Surface by description

A description-only "available skills" index is injected into the existing §20 L1 session primer (names + descriptions; full body hydrated on match) — no new index table. Going live off L4 is gated by an optional offline A/B replay (reusing the optimizer harness) that must not lower the judge score versus baseline.

REFINE · HERMES-ADOPT-5

Skill-curator lifecycle

Usage signals (use / view / patch counts + last_used_at) drive an Active → Stale → Archived ladder on the procedural ledger; Pin is an absolute exemption. Re-test rides the existing maintenance_runtime idle tick (no new cron engine); mutations are snapshot-before-mutate and skills are archived, never auto-deleted (reusing §05/§11 safety posture).

PROTECT · HERMES-ADOPT-6

Safe self-authoring

A generic pre-write content scan (prompt-injection / credential-exfiltration / Unicode-homoglyph / invisible-character) plus a trust-tier quarantine gate runs at the write-back seam before persistence on every self-authored artefact. This complements the faithfulness review (which checks fidelity); this checks malice. The frozen-snapshot trick keeps the LLM prefix cache stable within a session.

Brain-resident thresholds AGI-PURITY · PRINCIPLE 3

Per rules/bench-agi-purity.md, every tunable below lives in mcp-data/shared/memory-seed.sql (mirrored into AppSettings) and is read at runtime — never a literal in Rust source. The brain may re-tune them over time. Named keys (the contract for the seed lesson and this mirror):

hermes.skill_synthesis.min_recurring_success_cluster · hermes.skill_synthesis.recurrence_window_days · hermes.skill_synthesis.description_max_chars · hermes.skill_synthesis.name_max_chars hermes.skill_synthesis.cold_confidence · hermes.skill_synthesis.promotion_confidence_floor · hermes.skill_synthesis.ab_replay_win_margin · hermes.skill_synthesis.dedup_similarity hermes.curator.active_to_stale_idle_days · hermes.curator.stale_to_archived_idle_days · hermes.curator.max_synth_per_idle_tick hermes.security.trust_quarantine_floor

Safety & bounded proactivity

  • Anti-recursion: a synthesized skill cannot itself trigger unbounded synthesis — authoring is forbidden inside maintenance jobs, idle jobs cannot recursively enqueue further jobs, and hermes.curator.max_synth_per_idle_tick caps authoring per tick. The only proactivity adopted is bounded self-scheduling, not an open-ended "suggest next action" engine.
  • No-regression by construction: born-cold + advisory-only means an unproven skill is retrievable for audit but never auto-injected until it earns promotion through the §05 ledger and clears the A/B replay margin.
  • Security before persistence: every self-authored write passes the injection / exfiltration / homoglyph scan and trust-tier quarantine gate before it reaches the store — no self-authored artefact is persisted unscanned.
  • Reversible curation: curator mutations are snapshot-before-mutate and archive-never-delete (reusing §05/§11), with Pin as an absolute exemption.

09Infrastructure & capabilities around the brain

The brain is the hub, but a full companion needs ingestion, expression, voice, and embodiment. Each subsystem below is shipped (see the capabilities inventory) and is wired to the brain — feeding it data, surfacing its retrievals, or acting on its decisions. The vector backend, ingest connectors, and sentiment path are core to the memory loop; the avatar, audio, persona, and code-intelligence subsystems are the channels through which the brain perceives and acts.

MEMORY BACKEND · SPEC-019/020 NEW

Vector quantization tiers

The vector index spans four tiers: Linear → TurboVec / TQ+ → IVF-PQ → HNSW (usearch). TurboVec Phase 2 ships 2-bit per-coordinate quantization (BitWidth::Two) with Welford PerCoordStats calibration and an FWHT random rotation; QuantMind Phase 3 layers hierarchical document extraction (Thesis / Factor / asset-class detection) on top.

Tie to brain: 32× memory compression at ~97% recall@10 lets the long tier scale to 10M+ docs without RAM blow-up — the storage floor under §05.

MEMORY BACKEND · PHASE 49 NEW

IVF-PQ disk-backed ANN

An Inverted-File + Product-Quantization sidecar (4096 coarse cells, 96 subspaces × 256 centroids, 1-byte PQ codes, 32 nprobe) migrates shards to disk past a 5M-entry threshold using asymmetric distance computation.

Tie to brain: billion-scale retrieval for the L5 storage tier when the corpus outgrows in-RAM HNSW.

INGEST · SPEC-027/029 NEW

Connectors & scheduled sync

Four concrete ConnectorSource implementations — IMAP email, GitHub, RSS, and LocalFS — run as Tokio interval tasks (≥60 s) behind an AES-256-GCM credential vault, emitting a connector:sync_done event each cycle (GAP-001/002 fixed the flat-args contract).

Tie to brain: connectors are the brain's ingest pipeline — they feed documents and metadata into memory on a schedule, removing manual-ingestion friction.

EXPRESSION · SPEC-030 NEW

VTuber emotion bridge

Assistant text is scored for sentiment (brain/sentiment.rs → happy / sad / surprised / neutral) and blended onto the VRM avatar via applyEmotionToVrm with per-frame damping across 52 ARKit blendshape channels (intensity 0.6–0.8); 4 unit tests pass.

Tie to brain: the brain's emotional read of its own output becomes an embodied signal — the action side of perceive→act.

EXPRESSION · CAPTURE

Real-time sentiment & capture

The same sentiment path drives the conversation heatmap and the VTuber capture pipeline (MediaPipe PoseLandmarker + FaceLandmarker → Kalidokit → VRM bone Euler angles + blendshape weights, 640×480, GPU-accelerated). Expanded blendshape passthrough exposes all 52 ARKit channels with a safe probe-before-set no-op on stock rigs.

Tie to brain: live face/pose capture is a perception channel; sentiment timelines become auditable per-turn signals.

TRANSPARENCY · SPEC-026/031 NEW

Citations & conversation export

SourceCitations.vue renders pill chips ([N] index, cognitive_kind badge, source time-ago) under each reply, emitted via a source_attribution event from streaming.rs. export_conversation serializes the chat to JSON / Markdown with a sentiment timeline and an interactive citation map (memory_id / snippet / source_url / cognitive_kind / retrieved_at).

Tie to brain: makes the RAG pipeline auditable — users see exactly which memories powered each turn.

REACH · I18N

Multilingual / i18n

A language service indexes 180+ ISO 639-1 codes with BCP-47 compatibility and a per-message language-aware translation hook; the Real-E2E-024 suite passes 13/13 language probes (including Unicode ñ→es detection).

Tie to brain: language-aware retrieval and sentiment keep cross-lingual memories legible to a global audience.

DISCIPLINE · 12-RULE

Reasoning rules stack

A configurable 12-rule contract (4 Karpathy core + 8 extended) is persisted one-row-per-rule in reasoning_rules and injected as a compact (~1.2 kB) system-prompt block, each rule toggleable.

Tie to brain: explicitly steers the LLM's decision process around the retrieved-memory block — harness, not hardcoded logic.

CODE INTELLIGENCE

Repo RAG & @source scoping

Per-repo SQLite ingest with PageRank repo-map and secret pre-scan powers @source-id chat mentions: a composer autocomplete (self + owner/repo sources) routes cross_source_search with a per-turn source_overrides slot cleared after the turn.

Tie to brain: lets queries be constrained to specific knowledge sources without polluting the global memory pool.

EMBODIMENT · PERSONA

Persona packs & teachables

A self-describing JSON persona codec (version 1, 1 MiB cap, version-skew-tolerant) packages traits + learned expressions + learned motions with provenance and an import skip-report. A teachable-capabilities registry tracks 9 categories with usage/rating and an Untested→Learning→Proven→Canon maturity ladder (promotion ≥ 2.5 avg over 10 uses).

Tie to brain: proven capabilities are promoted through the same self-improve loop that governs procedural memory.

VOICE & AUDIO

TTS · song · BGM

A trait-based audio engine (ASR / TTS / diarization) drives on-device Supertonic TTS (ONNX, 5 languages) and Edge-TTS language routing. The Song Studio pipeline (ACE-Step, Suno V4.5, Stable Audio 2, MusicGen) plus Whisper ASR + RMVPE/PSOLA pitch analysis and a deduplicating SongCache power singing; Demucs splits stems and a BGM player loops ambient tracks.

Tie to brain: sing_lyrics and TTS are the brain's voice output; melody/prosody analysis feeds song context back as memory.

EMBODIMENT · ANIMATION

Animation studio & learned motion

A multi-track MMD-style editor (VMD/BVH import, FABRIK IK, MMD↔VRM retargeting, VQ-VAE codebook matching, ConditionalFlow locomotion) and an 8-state character FSM bake LearnedMotion clips into THREE.AnimationClip with fade timing; offline MediaRecorder export (VP9/H264) authors MVs.

Tie to brain: procedural animation is driven by learned motion codebooks — the avatar's action vocabulary, exported and replayed.

OPERATIONS · OBS / RESILIENCE NEW

Observability, schedules & resilience

A tracing::Layer writes spans/events to SQLite (zero-cost when TERRANSOUL_OBS_DISABLED=1) with hourly aggregation, PII sha256 redaction, FTS5 log search, and 5 MCP tools (obs_query/trace/logs/metrics/search). Tie to brain: every turn is traced (latency, tokens, tool calls), feeding trace-driven SkillOpt optimization and self-healing.

10The long-horizon gaming study — Zork I

Retrieval quality is static; acting over hundreds of turns is the harder test. TerranSoul's brain plays Zork I with a deliberately weak local model (gemma4:e4b, an effective-4B edge config) so that any score lift is attributable to the brain, not the model. The study uses three control arms, all holding model, strategy, and critic fixed:

ARM 1 · NONE

No memory

The weak 4B with episode-local context only. Score 0 — the unaided baseline: the weak model cannot play.

ARM 2 · ZORKGPT-DEFAULT

Upstream memory substrate

The same 4B with ZorkGPT's built-in MemoryManager + KnowledgeManager. Score 0 — a stock memory substrate alone does not help the weak model.

ARM 3 · TERRANSOUL-BRAIN

AGI-pure external brain

The same 4B with TerranSoul's brain and zero task seeds (no Zork verbs / walkthroughs in memory). Score 10–20 — the memory lift, achieved by externalizing task knowledge with no hardcoded game knowledge.

The principal result — delivery reliability is its own axis

Holding model, strategy, and critic fixed and only changing how a taught solution is delivered to the agent isolates delivery reliability as a distinct performance axis, separate from model capacity:

The same delivery change moved a 4B model from a non-deterministic 73 / 177 / death to a deterministic 350 / 350 — matching the no-LLM script-replay ceiling of 350 with 396/396 moves deterministic and 0 errors, despite a live agent and critic in the loop.

Even a frontier model drops from a perfect 350 on recall to 50 on cold reasoning — below ZorkGPT's scaffolded frontier of 115 — confirming that single-game long-horizon play is genuinely hard, and that the brain's contribution is the durable, externalized solution path rather than raw model strength.

Architectural stability under load

Across two canonical 2-episode × 100-turn runs the brain executed 1,682 MCP operations with 0 errors; the longer reliable-delivery demonstration ran 6,456 operations with 11 errors (0.17%) — well under the 5% threshold, with 5 reflections retrievable per episode. The takeaway: a score of 0 on the AGI-pure arm is the weak model's reasoning ceiling, not a memory failure — the brain delivers reliably; the model is the bottleneck.
